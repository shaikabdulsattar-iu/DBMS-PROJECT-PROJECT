1. Project Overview

The Software Management System is a database management project developed using SQLite and SQL. It is designed to store and manage software project information in a centralized database. It helps organize employee, client, project, task, team, milestone, and resource details in a structured way.

2. Objectives
To store and manage software project data in one database.
To maintain employee, department, and client information.
To track project progress, tasks, and milestones.
To manage teams and resource allocation.
To perform insert, update, delete, and retrieve operations using SQL.
To maintain data accuracy and consistency using database constraints.
3. Technologies Used
SQLite: Used to create and manage the database.
SQL: Used to create tables, insert data, update records, and retrieve information.
GitHub: Used to store project files, maintain code versions, and support team collaboration.
4. Database Tables

The project contains eight tables:

Table Name	Description
Department	Stores department details.
Employee	Stores employee information.
Client	Maintains client details.
Project	Stores project information and status.
Task	Tracks tasks assigned to employees.
Team	Maintains team details and project assignments.
Milestone	Tracks project milestones and deadlines.
Resource	Stores resources allocated to teams.
5. Key Features
Data Management: Add, update, delete, and view records.
Project Tracking: Maintain project status and deadlines.
Task Management: Track task priorities, status, and employee assignments.
Team Management: Organize teams and their resources.
SQL Operations: Retrieve and analyze data using JOINs, aggregate functions, and subqueries.
Data Integrity: Use primary keys, foreign keys, and constraints to maintain consistent data.
6. How to Run the Project
Download or clone the project from GitHub.
Open the SQL script in an SQLite-supported database tool.
Execute the script to create the database tables.
Insert the sample records into the tables.
Execute SQL queries to view, update, and manage the data.
