# SOFTWARE MANAGEMENT SYSTEM

## 📌 Project Overview

The **Software Management System** is a relational database project developed to efficiently manage and organize information related to **software, developers, projects, clients, teams, and licenses**.

The system provides a centralized database for storing accurate information and performing essential operations such as **data insertion, updating, deletion, searching, reporting, and analysis**.

---

## 🎯 Project Objectives

* To design and implement a structured relational database.
* To manage software development-related information efficiently.
* To maintain accurate and consistent records using database constraints.
* To establish relationships between different entities using **Primary Keys and Foreign Keys**.
* To demonstrate **DDL, DML, DQL, CRUD operations, Joins, Aggregate Functions, and Views**.
* To reduce data redundancy and improve data reliability.

---

## ❗ Problem Statement

Managing software-related information manually can result in **duplicate records, inconsistent data, difficulty in tracking projects, and inefficient information retrieval**.

Our system solves these problems by providing a **centralized and well-structured database** that makes software management easier, faster, and more reliable.

---

## 🗂️ Main Entities

| Entity        | Purpose                                          |
| ------------- | ------------------------------------------------ |
| **Software**  | Stores software details and versions             |
| **Developer** | Maintains developer information                  |
| **Project**   | Tracks software development projects             |
| **Client**    | Stores client details                            |
| **License**   | Manages software licenses and expiry information |
| **Team**      | Maintains development team information           |

---

## 🔑 Database Concepts Implemented

**Database Design → Tables → Relationships → Constraints → Data → Queries → Reports**

The project demonstrates:

* Primary Key & Foreign Key
* NOT NULL, UNIQUE, CHECK & DEFAULT constraints
* DDL Operations
* DML Operations
* DQL Queries
* CRUD Operations
* INNER/OUTER Joins
* Aggregate Functions
* GROUP BY & HAVING
* Subqueries
* Views
* Data Validation

---

## ⚙️ Key Features

* **Software Management** – Maintain software name, version, type, and related details.
* **Developer Management** – Store and manage developer information.
* **Project Tracking** – Track project details, dates, and status.
* **Client Management** – Maintain client records.
* **License Management** – Track license types and expiry dates.
* **Team Management** – Organize developers and projects.
* **Report Generation** – Retrieve meaningful information using SQL queries.

---

## 🛡️ Data Integrity

The database uses appropriate **constraints and relationships** to ensure:

> **No duplicate IDs + Valid Data + Consistent Relationships + Reliable Records**

Primary and foreign keys maintain entity relationships, while validation constraints prevent invalid or incomplete data.
